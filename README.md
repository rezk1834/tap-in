# Tap In website
1. `npm install` then `npm run dev` to preview.
2. Replace `public/logo.svg` with your logo (or use a PNG and change "/logo.svg" in src/App.jsx).
3. Add customers and links in `src/data.js`. A customer with slug `abc` lives at tapineg.site/abc.
4. Push to GitHub, import the repo in Vercel, add the domain tapineg.site. `vercel.json` already handles the page links.
